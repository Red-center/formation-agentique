# Projet : boutique (exercice de formation)

Petit module Python `boutique/catalogue.py` : pagination d'un catalogue produits et formatage des prix.

## Lancer les tests
- `pytest -q` depuis ce dossier (Python 3.10+, `pip install pytest`).
- Les tests doivent être verts avant de conclure.

## Règles
- Corriger la CAUSE du bug, pas le symptôme ; ne jamais modifier un test pour le faire passer.
- Garder les tests existants ; ajouter un test si le cas corrigé n'est pas couvert.
- Diff minimal : pas de refactoring, pas de nouvelle dépendance, pas de reformatage.
- Expliquer en 3 lignes : cause, correction, test qui le prouve.
